# Coverage AI 채팅 — 동작 기준표 (정본)

이 표가 정본이다. **이 표와 다르게 움직이는 것만 버그**로 고치고,
표를 바꾸는 것은 사용자 승인으로만 한다. (2026-09-27 확정)

## 원칙

1. **질문에 실제로 등장한 글자만 신호다** — LLM 이 현황·이전 맥락에서
   가져온 값(질문에 없는 IP 등)은 서버가 버린다. 값이 버려져도 의도가
   있었으면 사용자의 원문으로 후보를 찾아 카드로 묻는다.
2. **콕 집은 유일 대상은 그 말이 곧 선택** — IP·정확한 TC키(숫자 앞자리
   0 무시)·정확한 항목 이름. 그 외에는 전부 **후보 카드로 묻고 사람이
   클릭**해야 확정된다.
3. **한 번의 질문에는 한 단계만** — 한 문장에 여러 단계가 담겨도 장비 →
   항목 → 시작 순서로 하나씩 확인하며 간다.
4. **이미 고른 것은 유지** — 같은 장비·모델을 다시 말하면 안내만 하고
   갈아타지 않는다. 바꾸는 건 다른 IP 를 콕 집었을 때만.
5. 항목 후보 검색은 규칙 점수 + RAG(BM25·임베딩·bge-reranker, source=tc)
   리콜 → LLM(similar) 재선별. **후보 밖은 못 고른다.**

## 시나리오 표

| 말 | 기대 동작 |
|---|---|
| "사용 가능한 장비 알려 줘" | 한 줄 답 + **사용 가능만** 장비 카드 |
| "장비 목록 보여 줘" | 한 줄 답 + 전체 장비 카드 (상태 표시) |
| "220.1.12.3 장비 선택 해" | **즉시 확정** — 1단계 확인 줄 + 다음 단계 안내 |
| "E6100 선택 해" (여러 대) | 그 모델 후보 카드 (가능·불가 모두, 추천 배지) |
| "E6100 시스템 정보 조회 시험해줘" | 장비 카드부터 → 클릭 → 항목 후보 → 클릭 → 절차 준비 |
| "E61xx-T0004 선택" / "T004 선택" | **즉시 확정** (키 정규화) → 절차 준비. 장비 없으면 장비 고르개 |
| "sysName ( … ) Get 동작 확인 선택" (정확 이름) | 즉시 확정 |
| "시스템 이름 항목 선택/보여 줘" (한글 뜻) | 후보 카드 (RAG+LLM 검색, 추천 이유 표시) |
| "시험 항목 어떤 게 있어" | 한 줄 답 + 항목 카드 목록 (30건 컷 + 전체에서 검색) |
| "시험 시작 해" (절차 준비됨) | **즉시 실행** (▷ 버튼과 동일) |
| "시험 시작 해" (절차 없음) | "장비·항목을 먼저 선택해 주세요" |
| "결과를 보여 줘" (실행 후) | 결과 보기(3열) 열림 |
| "안녕" / 일반 질문 | 텍스트 답만, 목록에 대화 기록 저장 |
| 못 찾는 말 | "찾지 못했습니다 — ○○로 직접 선택" (조용히 무시 금지) |
