# Devices · Traffic Gen · Rack View — 장비와 계측기

## 무엇을 하는 화면인가

시험에 쓰는 **장비**(스위치·OLT·ONT 등)와 **계측기**(Spirent TestCenter, IXIA N2X)를 등록하고, 접속되는지 확인하고,
랙에 어디 꽂혀 있는지 그린다. 시험 항목의 스텝은 여기 등록된 장비로 나간다.

## 어디 있나

왼쫏 메뉴 RESOURCES › **Devices**(장비 목록과 카탈로그) · **Traffic Gen**(계측기) · **Rack View**(랙 그림).

## 하는 일

### 장비 (Devices)
- **키는 IP** 다. 같은 모델이 여러 대여도 IP 로 갈린다. 「+ 장비」 로 IP·이름·모델·역할(L2·L3·OLT·ONT·CPE·HGW·계측기·기타)·LAB·사업자를 적는다.
- **접속 정보** — telnet·ssh·console·SNMP 를 프로토콜별로 따로 둔다(포트·계정·암호·커뮤니티). 기본 프로토콜을 하나 정한다.
  암호는 DB 에 그대로 들어간다. CSV 내보내기는 기본으로 암호를 빼고, 필요할 때만 「비밀 포함」 으로 받는다.
- **접속 확인** — 줄의 「확인」 이나 「이 LAB 전부 접속 확인」. 로그인까지 하지 않고 **포트가 열려 있나**만 본다.
  (잘못된 계정으로 여러 번 시도하면 장비가 계정을 잠그기 때문이다.) SNMP 는 sysDescr 을 실제로 읽어 본다.
- **SNMP 포트 훑기** — SNMP 가 등록된 장비는 인터페이스 목록을 SNMP 로 읽어 인터페이스 칸을 채운다.
- **CSV 들이기·내보내기** — 「내보내기」 로 받은 파일의 머리줄 그대로 채워 「들이기」 한다. 먼저 미리보기(dry run)로 무엇이 새로 생기고
  바뀌는지 본 뒤 저장한다. 필수 열은 IP 다.
- **장비 카탈로그** — 제조사·제품군·모델명의 사전이다. 모델명은 시험 항목과 사이클이 물려 있어 여기서 못 바꾼다(다른 것은 바꿀 수 있다).
  옛 카탈로그(설정 KV)와 백업도 아직 읽을 수 있다.
- **점유** — 실행 중인 사이클이 장비를 잡으면 목록에 누가 잡았는지 보인다(30초마다 갱신). 자원 잠금은 [cycles.md](cycles.md).

### 계측기 (Traffic Gen)
- **Spirent STC** — REST 서버(stcweb)가 윈도우 PC 에서 돈다. 여기서 섀시 연결 확인, 포트 예약·해제, 트래픽 시작·통계·정지를 한다.
  리눅스 서버에서는 stcweb 을 띄울 수 없으므로 윈도우 PC 의 REST 주소를 적어 둔다.
- **IXIA N2X** — Tcl 데몬이 필요하다. 리눅스 서버는 직접 못 하므로 **윈도우 중계**(`tools/n2x_relay.py`)로 넘긴다.
  `.env` 의 `N2X_RELAY_URL`·`N2X_RELAY_KEY` 로 붙인다([../N2X_RELAY.md](../N2X_RELAY.md)). 포트 예약·해제, ARP, 트래픽 시작·통계·정지·초기화.
- 시험 항목의 **계측기 스텝**은 이 화면이 아니라 사이클 실행 때 실행기가 여기 길을 부른다.

### 랙 (Rack View)
- 랙 틀(이름·높이)을 만들고 장비를 끌어다 칸에 놓는다. 겹치면 서버가 거절한다(두 사람이 같은 칸에 동시에 놓을 때).
- 빈 칸 부품(blank)과 부품 견본을 둘 수 있다. 빈 값으로 저장하면 기존 배치를 덮지 않게 거절한다.
- 아직 랙에 안 놓인 장비는 「미배치」 로 따로 보인다.

## 규칙과 주의

- 장비 표에 실제 IP·계정·암호가 평문으로 있다. DB 덤프를 밖으로 내지 않는다.
- 접속 확인의 실패는 「길이 막혔다」 는 뜻이지 「로그인이 틀렸다」 는 뜻이 아니다.
- 계측기 스텝이 「N2X Tcl 이 이 서버에 없습니다」 로 답하면 중계 설정을 본다.

## 관리자가 할 일

- `.env`: `N2X_RELAY_URL`·`N2X_RELAY_KEY`(N2X), 윈도우 PC 의 STC REST 주소. SETUP › **코드표**: 역할·LAB 선택지.

## 동작 확인

```bash
./tools/smoke.sh devices
```

대본 `tests/smoke/devices_smoke.py`: 역할 목록 → 모델 카탈로그 저장·목록, 이름 바꾸기는 막히는가(설계) → 장비 저장·목록·읽기 →
접속 확인이 닫힌 포트에 실패로 답하는가 → SNMP 포트·기본 프로토콜·CSV 내보내기·들이기 미리보기 → 랙 저장, 빈칸 id 채움, 배치, 랙뷰,
빈 값으로 덮기 거절 → 옛 카탈로그·백업·옛 장비 목록 → STC·N2X 길이 계측기 없을 때 500 대신 안내인가, 데몬·중계 스크립트 파일이 잡히는가 →
장비·모델 지우기. 41개.
